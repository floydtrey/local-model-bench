# Project Intent — Worker Qualification Fixture 01

Add support for a configurable report title while preserving existing report behavior.

The final completed project should:
- allow ReportConfig to carry an optional title with default value "Report";
- render that configured title as the first report line;
- preserve every later report line exactly as before;
- preserve existing public function signatures and existing callers;
- add no third-party dependencies;
- include tests for default and custom titles.

Prefer the smallest change that satisfies the requirement. Reuse the existing project structure and tests. Do not perform unrelated refactors or add unrelated features.
